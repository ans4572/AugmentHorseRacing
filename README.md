# 🏇 증강 경마 (Augment Derby)

6마리의 우스꽝스러운 말이 자동으로 달리고, 최대 8명의 플레이어가 결과를 예측해 가상 코인을 배팅하며, 경기 도중 3번의 증강 카드로 서로의 승부를 뒤흔드는 **웹 기반 실시간 멀티플레이 파티 게임**입니다.

기획서: [증강 경마 (Augment Horse Racing) 기획서.md](<증강 경마 (Augment Horse Racing) 기획서.md>)

## 게임 방법

1. **방에 모이기**: 한 사람이 "방 만들기"로 방을 만들고, 로비에 나오는 초대 코드 6자리를 친구에게 알려 줍니다. 친구는 "방 참가"에서 코드를 입력합니다. 혼자라면 "혼자 하기"로 NPC 5명과 바로 시작합니다.
2. **출마표 보기**: 라운드마다 여섯 마리가 새로 나옵니다. 속력·가속·지구력·컨디션은 10점 만점이고, 몸무게는 kg입니다. 말마다 배당이 다릅니다.
3. **배팅하기 (2분)**: 말을 고르고, 배팅 종류를 고르고, 금액을 정해 겁니다. 가진 코인을 전부 거는 올인도 됩니다. 여러 장을 걸 수 있고, 마감 전에는 취소할 수 있습니다.

   | 배팅 종류 | 맞히는 조건 |
   |---|---|
   | 우승마 | 고른 말이 1등 |
   | 꼴찌마 | 고른 말이 6등 |
   | 1~3위 | 고른 말이 1, 2, 3등 중 하나 |
   | 4~6위 | 고른 말이 4, 5, 6등 중 하나 |

   맞히면 `건 금액 × 배당`을 돌려받습니다(소수점 버림). 다 걸었으면 "준비 완료"를 누릅니다. 모두 누르면 바로 마감되고, 다시 누르면 취소됩니다.
4. **배팅 공개**: 누가 어디에 걸었는지 보여 줍니다. 블라인드 방에서는 내 배팅만 보이고 나머지는 라운드 결과에서 공개됩니다. 경주 중에는 상단의 "배팅 현황" 버튼으로 다시 볼 수 있습니다.
5. **경주와 증강**: 경주는 멈추지 않고, 그 사이 증강 카드를 다섯 번 받습니다. 매번 3장 중 1장을 골라 말을 돕거나 방해합니다.
   - 카드는 증강 지점보다 조금 앞에서 미리 보입니다. 미리 골라 두면 선두가 지점에 닿는 순간 발동하고, 그 전에는 바꿀 수 있습니다.
   - 한 구간의 등급은 모두에게 같고, 카드는 사람마다 다릅니다. 뒤로 갈수록 높은 등급이 잘 나옵니다.
   - 카드마다 새로고침 버튼이 하나씩 있습니다. 누르면 그 카드만 같은 등급의 다른 카드로 바뀌고, 카드 자리마다 한 번만 쓸 수 있습니다.

   | 구간 | 증강 지점 | 미리보기 시작 | 지점 이후 고르는 시간 | 실버 / 골드 / 플래티넘 확률 |
   |---|---|---|---|---|
   | 1차 | 10% | 5% | 7초 | 65% / 28% / 7% |
   | 2차 | 30% | 25% | 6초 | 50% / 37% / 13% |
   | 3차 | 50% | 45% | 6초 | 38% / 42% / 20% |
   | 4차 | 70% | 65% | 5초 | 28% / 42% / 30% |
   | 5차 | 90% | 85% | 5초 | 20% / 40% / 40% |

6. **정산과 우승**: 라운드가 끝나면 배팅을 정산합니다. 코인이 10 미만으로 떨어지면 다음 라운드에 100코인으로 채워 줍니다. 모든 라운드가 끝났을 때 코인이 가장 많은 사람이 이깁니다.

## 기술 스택

- **언어:** TypeScript (클라이언트·서버·공유 코드 전체)
- **프론트엔드:** Vite + Three.js (3D 경주 화면) + HTML/CSS (메뉴·배팅·카드 UI)
- **서버:** Node.js + `ws` (WebSocket), 서버 권한(server-authoritative) 고정 틱 시뮬레이션 (20Hz 시뮬레이션 / 10Hz 상태 전송)
- **테스트:** Vitest (185개 테스트 — 증강 66종 각각의 효과 검사, 내 말·당근 보상 검사, 배경음악 악보 검사 포함)
- **데이터:** 서버 메모리 기반 (DB 없음 — MVP 기준)

## Cloudflare 배포

게임 서버와 화면을 Cloudflare Workers 하나로 올립니다. 화면(정적 파일)은 Workers Static Assets가 내려 주고, WebSocket(`/ws`)은 Durable Object 하나가 모두 받아 방과 경주를 메모리에서 돌립니다. 로컬 Node 서버와 같은 `server/src/hub.ts`를 쓰므로 규칙이 똑같습니다.

```bash
npx wrangler login     # 처음 한 번: 브라우저에서 Cloudflare 계정 승인
npm run deploy         # 빌드 후 배포. 끝나면 https://augmenthorseracing.<계정>.workers.dev 주소가 나옵니다
npm run cf:dev         # 배포 전에 로컬에서 Cloudflare 방식으로 실행 (http://localhost:8787)
```

- 설정 파일은 `wrangler.jsonc`, 진입점은 `worker/src/index.ts` 입니다.
- 새로 배포하면 Durable Object가 다시 시작되어 진행 중이던 방이 사라집니다 (방은 메모리에만 있습니다).
- 접속자가 모두 나가면 객체가 잠들고, 다음 접속 때 다시 깨어납니다.

## 혼자 하기 (싱글 모드)

메인 화면의 **🎮 혼자 하기 (NPC 5명)** 버튼을 누르고 라운드 수를 고른 뒤 **바로 시작!** 을 누르면, NPC 5명과 6인전이 로비 대기 없이 곧바로 시작됩니다. NPC 5명은 성격이 서로 다릅니다(승부사·방해꾼·복수귀·도박꾼·천사). 사람은 혼자이므로 "능력치 확인 완료 / 배팅 마감" 버튼을 누르면 대기 시간이 바로 넘어갑니다. 서버(`npm run dev`)는 켜져 있어야 합니다.

### 내 말과 마구간

혼자 하기에서는 **내 말 한 마리가 6마리 중 하나로 출전**합니다. 레인과 능력치는 매 라운드 무작위이고(꾸미기는 겉모습만 바꿉니다), 출전마 카드·이름표·미니맵·카메라 버튼에 ⭐ 로 표시됩니다. 내 말에 걸어도 되고 다른 말에 걸어도 됩니다.

**멀티에서도 내 말이 출전합니다.** 방을 만들거나 참가할 때 내 말이 함께 등록되고, 한 게임에서 **2번**(라운드가 1번뿐이면 1번) 나옵니다. 한 라운드에는 6마리까지만 나오므로, 말을 데려온 사람이 많아 자리가 모자라면 무작위로 뽑힙니다. 모두가 한 번씩 나온 뒤에 두 번째 차례를 채웁니다. 다른 사람의 말에는 "○○의 말" 딱지가 붙고, 순위 상금과 게임 종료 보너스(당근)는 말을 데려온 사람 각자에게 나옵니다.

게임을 하면 **당근 🥕** 이 쌓이고, 메인 화면의 **🐴 내 마구간**에서 당근으로 꾸미기를 삽니다.

| 당근을 받는 때 | 양 |
|---|---|
| 처음 마구간을 열 때 | 100 |
| 라운드마다 내 말의 순위 상금 | 1위 60 · 2위 40 · 3위 25 · 4~6위 10 |
| 게임 종료 시 최종 순위 보너스 | 1위 120 · 2위 70 · 3위 40 · 그 외 15 |
| 게임 종료 시 배팅 순이익 보너스 | 순이익의 10% (최대 200, 손해면 0) |

꾸미기는 6칸 29종입니다: 종류(말·당나귀·젖소 무늬 말·얼룩말·유니콘), 털 색 7종, 모자 6종(고깔·밀짚·신사 모자·프로펠러·왕관), 목 4종(목도리·나비넥타이·금메달), 얼굴 3종(선글라스·분홍 안경), 발자국 4종(분홍 구름·금가루·무지개). 사기 전에 눌러서 3D 미리보기로 입혀 볼 수 있고, 말 이름(최대 8자)도 바꿀 수 있습니다.

내 말이 2위 안에서 달리면 NPC가 방해 카드로 내 말을 조금 더 자주 노립니다(자기가 내 말에 건 NPC는 제외). 내 말에 강화 카드를 몰아주기 쉬워진 만큼 균형을 맞춘 것입니다.

당근과 꾸미기는 **이 브라우저의 localStorage**에 저장됩니다. 브라우저를 바꾸거나 사이트 데이터를 지우면 초기화됩니다.

## 로컬 멀티플레이 테스트 방법

1. `npm run dev` 실행
2. 브라우저 탭 2개 이상에서 http://localhost:5173 접속 (재접속 토큰이 탭 단위 `sessionStorage`라 같은 PC의 여러 탭이 각각 다른 플레이어가 됩니다)
3. 탭 A: **방 만들기** → 라운드 수·인원·NPC 수 설정 → 방 생성
4. 탭 B: **방 참가** → 공개 방 목록에서 참가 (비공개 방은 6자리 초대 코드 입력)
5. 탭 A(방장): **게임 시작** — 혼자 테스트할 때는 NPC 1명만 추가해도 시작 가능
6. 같은 네트워크의 다른 기기(휴대폰 포함)에서는 `http://<PC의 IP>:5173`으로 접속하면 함께 플레이할 수 있습니다 (Vite가 `--host`로 열려 있음)

팁: "능력치 확인 완료 / 배팅 마감" 버튼을 모든 사람이 누르면 대기 시간을 건너뛰고 바로 진행됩니다.

## 구현 완료 기능

**게임 진행**
- 메인 화면 / 방 생성(이름·공개여부·초대코드·최대 2~8명·1~5라운드·NPC 수·배팅 공개 방식) / 공개 방 목록·코드 참가 / 대기 로비
- 라운드 수에 따른 초기 코인 지급 (500/800/1,100/1,400/1,700) — 게임 시작 시 1회, 라운드 간 이월
- 코인 부족 구제: 10코인 미만이면 다음 라운드 시작 시 100코인으로 보충
- 능력치 확인(20초) → 배팅(2분, 모두 준비 완료를 누르면 바로 마감) → 배팅 공개(5초) → 카운트다운 → 경주 → 라운드 정산 → 최종 결과
- 전원 준비 시 대기 단계 조기 종료, 방장의 다음 라운드 진행, 같은 방에서 다시 하기

**말 / 경주**
- 매 라운드 6마리 무작위 생성: 속력·가속력·지구력·몸무게·컨디션, 능력치 총합 제한, 코믹한 이름 풀
- 서버 권한 20Hz 고정 틱 시뮬레이션: 가속/최고속도, 지구력 고갈 시 피로 감속, 몸무게의 가속 영향, 컨디션 수치에 따른 소규모 속력 변동
- 결승선 통과 시각 틱 간 보간 판정, 동률 시 말 ID 순 판정
- 클라이언트 보간 렌더링, 긴 스크롤 트랙 + 카메라 추적(선두/특정 말 선택), 미니맵, 치비 카툰 말 + 상태별 애니메이션(부스트·수면·넘어짐·비행·역주행·피로)

**배팅**
- 우승마 / 꼴찌마 / 1~3위 / 4~6위 (배팅 유형은 데이터 구조상 확장 가능)
- 몬테카를로 시뮬레이션(220회) 기반 배당 계산, 배당 고정·범위 제한·소수점 2자리
- 최소 10코인, 라운드 총 배팅 한도 = 배팅 시작 시 보유 코인의 30%, 복수 배팅, 마감 후 수정 불가
- 지급액 = floor(배팅금 × 배당) (원금 포함), 전원 배팅 공개(경기 중에도 사이드바에 표시)
- **블라인드 배팅(방 옵션):** 방을 만들 때 "배팅 공개 방식"을 블라인드로 고르면, 라운드 결과가 나오기 전까지 각자 자기 배팅만 보입니다. 다른 사람은 "배팅 N건"으로만 표시되고, 결과 화면에서 전부 공개됩니다

**증강**
- 선두 말 10% / 30% / 50% / 70% / 90% 도달 시 증강 구간 (7초/6초/6초/5초/5초, 코스 길이 1400), **선택 중에도 경주 계속 진행**
- **등급제(실버·골드·플래티넘):** 구간마다 등급을 한 번 뽑아 모든 플레이어가 같은 등급을 받고, 카드 3장은 그 등급 안에서 플레이어마다 따로 뽑습니다. 구간당 1장 사용, 미선택 시 소멸
- 등급 구성: 실버 25종 · 골드 24종 · 플래티넘 8종 (일반=실버, 희귀=골드, 영웅+전설=플래티넘). 등급은 실제 측정한 효과 크기에 맞춰 배정했습니다. 한 장이 완주 시각을 바꾸는 폭은 실버 약 0.5~1.3초, 골드 약 0.8~2.5초, 플래티넘 약 1.4~4.3초입니다
- **카드 이름과 설명은 웃기게 다시 지었습니다.** 효과는 기획서 그대로이고 이름만 다릅니다 (예: 로켓 부스터 → 엉덩이 로켓, 역주행 본능 → 가스불 안 껐다, 1등의 수난 → 1등 인터뷰, 인기마의 비극 → 연예인 병). 전체 목록은 `shared/src/augments.ts`, 기획서 이름과의 대응은 카드 `id`로 확인할 수 있습니다
- **증강 점검 도구:** `npm run audit:augments`를 실행하면 모든 카드를 같은 조건에서 걸어 보고, 1초 이동 거리·8초 뒤 위치 차이·완주 시각 차이를 표로 출력합니다. 효과가 없거나 방향이 반대인 카드는 ⚠로 표시됩니다
- **코믹 변신 증강 13종:** 이족보행, 조랑말 변신, 단체 조랑말, 기린 목, 풍선 말, 거대화, 종이 말, 문워크, 빙글빙글, 디스코 타임, 간지 폭발(선글라스), 깡충깡충, 방귀 부스터. 효과는 속력 증감·정지처럼 단순하고, 3D 화면에서 말의 모습이 실제로 바뀝니다
- **말 종류 5종:** 말·얼룩말·유니콘·당나귀·젖소 무늬 말. 겉모습만 다르고 능력치에는 영향이 없습니다. 털 색이 레인 색과 다른 종류는 안장과 목도리가 레인 색입니다
- 등급 확률(실버/골드/플래티넘): 1차 60/30/10 · 2차 35/45/20 · 3차 20/40/40 — 뒤 구간일수록 높은 등급이 잘 나옵니다
- 카드 66종: 기획서의 44종(단일 강화 8·단일 방해 8·홀짝 6·선두권/하위권 8·능력치 기반 6·특수 8) + 코믹 변신 13종 + 판을 흔드는 카드 9종(한눈팔기, 자석, 나란히 달리기, 어부바, 치어리더 등장, 당근 낚싯대, 재채기 릴레이, 결승선 당기기, 자리 뽑기). 6마리 전체가 대상인 카드는 판 자체를 바꾸는 전설 두 장(결승선 당기기, 자리 뽑기)뿐이고 마지막 구간에는 나오지 않음
- 대상은 서버 적용 시점에 확정, 완주한 말 자동 제외, 동률 시 낮은 ID
- 중첩 제한(카드당 2회), 정지 시간 비합산, 속력 배율 0.2~2.0 제한, 방어막/비행 면역, 서버 측 최종 검증(무효 시 카드 소모 없이 재선택 가능)

**멀티플레이 / NPC**
- WebSocket 실시간 동기화, 서버 접수 순서대로 증강 처리, 재접속 시 전체 상태 복구(방·코인·배팅·경주·진행 중 증강 선택)
- NPC 6종 성격(승부사·방해꾼·복수귀·도박꾼·천사·혼돈의 왕): 배당 분석 배팅, 성격별 가중치 증강 선택, 일정 확률의 비효율적 선택
- 연결 끊긴 플레이어에게 자동 증강 사용 없음, 방장 승계, 빈 방 자동 정리

**결과 / 연출**
- 말 순위·기록, 플레이어별 배팅 정산 표, 라운드별 현재 순위, 최종 순위(동률: 순이익→적중 횟수→공동 순위)

## 최근 규칙 변경

- **방은 초대 코드 전용:** 공개 방 목록을 없앴습니다. 방을 만들면 나오는 6자리 코드를 친구에게 알려 주면 됩니다.
- **준비 완료 취소:** 준비 완료를 다시 누르면 취소되어 배팅을 고칠 수 있습니다.
- **배팅 한도 없음:** 가진 코인을 전부 거는 올인이 가능합니다. NPC는 전처럼 가진 코인의 30%까지만 겁니다.
- **증강 미리 고르기:** 카드는 증강 지점(10/30/50/70/90%)보다 코스 5% 앞에서 미리 보입니다. 미리 골라 두면 선두가 지점에 닿는 순간 발동하고, 그 전에는 다른 카드로 바꿀 수 있습니다. 고르지 않은 사람은 지점 이후 5~7초 동안 고를 수 있습니다.
- **배팅 현황:** 상단의 배팅 현황 버튼을 누르면 배팅 공개 때와 같은 목록이 뜹니다. 블라인드 방에서는 내 배팅만 내용이 보입니다.
- **말에 맞춘 이름:** 사람의 생활에서 따온 카드 15종의 이름과 설명을 말의 상황으로 바꿨습니다 (예: 칼퇴 워프 → 지름길 발견, 월요병 전염 → 하품 전염, 과속 단속 → 고삐 당기기). 인생 역전은 말생 역전이 됐습니다. 효과와 수치는 그대로입니다.
- **카드 효과음:** 56종은 Freesound의 녹음(대부분 CC0)을 2초 이내로 다듬어 쓰고, 나머지는 코드로 합성한 소리를 씁니다. 출처는 `client/public/sfx/CREDITS.md`에 있습니다.
- **증강 수치:** 코스가 길어지며 과해진 카드를 낮췄습니다 (득근 각성 +8%, 아아 수혈 지구력 20%, 에너지 드링크 12%, 꼴찌 전용 보양식 18%). 약했던 목 프로펠러는 +50%, 마감 직전 파워는 5초로 올렸습니다.

## 소리

음원 파일 없이 브라우저의 Web Audio로 직접 합성합니다. 옛 게임기처럼 사각파 가락, 사각파 화음, 삼각파 베이스, 잡음 북 네 가지만 씁니다. 세 곡 모두 이 게임용으로 새로 지은 곡입니다.

| 곡 | 나오는 곳 | 분위기 |
|---|---|---|
| `menu` | 메인·방 만들기·마구간·대기실·최종 결과 | 다장조, 144BPM, 쿵짝쿵짝 통통 튀는 행진 |
| `paddock` | 출마표·배팅·배팅 공개·라운드 결과 | 바장조, 112BPM, 살금살금 걷는 스윙 |
| `race` | 경주 중 | 사장조, 176BPM, 말발굽(다-다닥) 리듬 |

- **효과음 23종:** 버튼, 배팅 접수·취소, 배팅 마감 5초 전 재촉, 카운트다운, 출발, 증강 등장(등급이 높을수록 높은 음), 아군·방해 카드, 방어막, 결승, 적중 축하, 전부 빗나감(뿜뿜뿜), 당근, 최종 우승 등.
- **켜고 끄기:** 메뉴 화면 오른쪽 위와 게임 전광판에 배경음악·효과음 버튼이 따로 있습니다. 설정은 브라우저에 저장됩니다(`augment-derby-sound-v1`).
- **첫 소리:** 브라우저 정책 때문에 화면을 한 번 누른 뒤부터 소리가 납니다.
- **악보 고치기:** `client/src/music.ts`에 한 마디를 16칸으로 적습니다(`E5:2`는 E5를 2칸, `-`는 쉼표). 마디 길이가 틀리면 테스트가 실패합니다.

- **배팅 유형 확장:** 1·2등 조합, 정확한 1·2등, 순위 대결 (타입·정산 구조는 확장 가능하게 설계됨)
- **사운드 확장:** 음량 조절 막대, 경주 막판에 빨라지는 음악, 증강 카드별 전용 효과음은 아직 없음 (지금은 아군·방해 두 가지 소리)
- **고급 연출:** 증강별 전용 파티클(폭발·번개 등)은 아직 없음. 외부 3D 모델을 쓰면 말 품질을 더 올릴 수 있음
- **재미있는 기록 확장:** 오늘의 배신자, 기적의 역전상, 가장 많이 방해받은 말 등 (현재 3종만 집계)
- **싱글 모드 동기 부여 2~3단계:** 미션·업적, 증강 도감, 리그 승급, 파산 서바이벌은 아직 없음 (1단계인 내 말·당근·꾸미기만 구현)
- **멀티플레이에서 내 말·꾸미기 사용:** 현재는 싱글 모드 전용. 당근 저장도 계정 없이 브라우저 단위
- **관전자 모드 / 게임 중 입장:** 현재는 로비에서만 참가 가능
- **지속 저장:** 서버 재시작 시 방 소멸 (DB 없음 — MVP 기준)
- **보안:** 간단한 재접속 시크릿만 사용. 공개 배포 시 레이트 리밋·입력 검증 강화 필요
- **배포:** 프론트 정적 호스팅 + 서버 별도 배포 구성 문서화 필요 (현재 로컬 기준)

## 3D 경주 화면

경주 화면은 Three.js 기반 3D입니다. 서버는 말의 위치만 보내고, 그리는 일은 `client/src/race3d.ts`가 맡습니다. (초기의 Phaser 2D 화면은 제거했습니다.)

- **카메라 시점:** 경주 화면 우상단 `🎥` 버튼으로 중계(앞쪽 대각선) → 측면 → 추격 → 공중 순환. 관전 대상은 👑(선두) 또는 1~6번 말 버튼으로 고릅니다.
- **말 모델:** 외부 3D 모델 파일 없이 구·원기둥 도형을 조립한 치비 스타일입니다 (`client/src/race3d.ts`의 `buildRig`). 색은 말 번호별로 자동 적용됩니다.
- **카드별 연출:** 비틀비틀(스텝 꼬임·급똥 신호), 대두(연예인 병), 카메라 보고 포즈(1등 인터뷰), 고개 숙여 먹기(당근 먹방), 풍선(헬륨 가스) 등 기존 카드에도 전용 모습을 붙였습니다
- **연출:** 갤럽 다리 애니메이션, 발굽 먼지, 부스터 불꽃, 벌크업/다이어트 시 몸집 변화, 비행 날개, 넘어짐, 역주행 시 뒤돌기, 방어막, 증강 대상 링, 방해 시 카메라 흔들림, 결승 후 우승마 회전 카메라.
- **이름표:** 말이 몰려 있어도 겹치지 않게 화면에서 서로 밀어내 배치합니다.
- **증강 카드가 떠 있을 때:** 카메라가 말을 화면 위쪽으로 잡아 카드에 가려지지 않습니다.
- **모바일:** 가로 화면 높이에 맞춰 3D 화면 크기를 줄입니다.
- **WebGL 미지원 기기:** 경주 화면 자리에 안내 문구가 나오고, 배팅과 결과 화면은 그대로 진행됩니다.
- **용량:** 클라이언트 묶음 gzip 약 155KB.
- **파일:** `client/src/race3d.ts` (3D 화면), `client/src/showcase.ts` (확인용 화면).

**쇼케이스:** 주소 뒤에 `?showcase`를 붙이면 (예: `http://localhost:5173/?showcase`) 서버 없이 말 종류와 변신 연출을 차례로 보여 주는 확인용 화면이 열립니다. `?showcase=broadcast`처럼 시점(broadcast·side·chase·top)을 고를 수 있습니다.

참고: 개발 서버 포트는 `PORT` 환경 변수를 따릅니다 (없으면 5173). 다른 프로젝트가 5173을 쓰고 있다면 `PORT=5174 npm run dev:client`처럼 다른 포트를 지정하세요.
