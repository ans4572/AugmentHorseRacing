📖 게임 방법

  1. 방을 만들고 친구를 초대하세요 (같은 PC의 여러 브라우저 탭도 OK).
  2. 매 라운드 6마리 말의 능력치를 확인하고 결과에 코인을 배팅하세요. (보유 코인의 30%까지)
  3. 배팅이 끝나면 모두의 배팅이 공개됩니다. 누가 어떤 말을 미는지 확인!
  4. 경주 중 25% / 50% / 75% 지점에서 증강 카드 3장이 주어집니다. 1장을 골라 말을 강화하거나 방해하세요. 고르는 동안에도 경주는 계속됩니다!
  5. 모든 라운드가 끝나면 보유 코인이 가장 많은 사람이 우승!
